# Tinariox changelog

## v20.0-demo (beta) — 2026-10-10

First public beta of the Tinariox Android app (APK-only distribution).

### Included

- Chat with local / OpenAI-compatible LLM servers (streaming)
- On-device voice input and speech output
- Companion onboarding and personalities
- Memory, facts, knowledge graph
- Tasks and reminders
- Document Q&A (PDF)
- LAN server discovery

### Not in this build

Several experimental modules from earlier prototypes are **not included** in the public beta and remain under active development (CV / vision, smart home, multi-agent, ComfyUI, code execution, games, and related prototypes). The beta focuses on a stable core: chat, voice, companion, memory, tasks, documents.
